AI에게 시키는 법

“읽을 수 있는” 코드를
따로 요구해야 한다

문제 게임 점수판을 만들어줘. 점수가 올라가는 걸 화면에 보여줘. 조건 나는 초등학생이고 이 코드를 읽어서 이해할 거야. ① 한 줄에 한 가지만 해줘 ② 이름을 길고 뜻이 보이게 지어줘 (s 말고 score) ③ 짧게 줄이는 문법은 쓰지 마 (삼항연산자, 화살표 줄임) ④ 주석은 달지 마 — 주석 없이 읽을 수 있어야 해 ⑤ 다 쓴 뒤에 설명하지 마. 나는 코드만 볼 거야.
왜 주석을 막나

주석이 있으면
코드를 안 읽는다

주석이 있으면

한글만 읽고 넘어간다

“// 점수를 1 올린다” — 이걸 읽고 다 안 것 같지만, 코드는 한 글자도 안 봤다.

주석이 없으면

코드를 볼 수밖에 없다

읽고 나서 내가 주석을 직접 단다. 그게 오늘의 숙제다.

오늘은 내가 주석을 다는 사람이다. AI가 아니라.
01 · 변수

값에 이름표를
붙이는 일

let score = 0; let playerName = "민준"; score = score + 10; score = score + 5;
“상자에 넣는다”는 설명은 나중에 헷갈린다. 이름표를 값에 붙인다고 읽자 — 이름표는 떼서 다른 값에 붙일 수 있다.
읽기 2동작 · 값 추적표

줄이 넘어갈 때마다
손으로 적는다

줄 score playerName let score = 0; 0 — let playerName = "민준"; 0 "민준" score = score + 10; 10 "민준" score = score + 5; 15 "민준"
이 표를 채울 수 있으면 그 코드는 읽은 것이다. 못 채우면 아직 못 읽은 것이다.
가장 큰 오해

= 는
“같다”가 아니다

수학에서

score = score + 1

“어떤 수가 자기보다 1 큰 수와 같다”? 그런 수는 없다. 말이 안 된다.

코드에서

오른쪽을 먼저 계산한다

score + 1 을 먼저 구하고, 그 값에 score 이름표를 다시 붙인다. 순서가 있다.

그래서 오른쪽부터 읽는다. 이 한 가지만 알아도 코드가 갑자기 읽힌다.
고장 내기 1

일부러
부숴본다

  • let score = 0; 줄을 지운다 — 무슨 에러가 나나? 그 에러 문장을 그대로 적어둔다
  • score 를 전부 s 로 바꾼다 — 돌아가나? 돌아간다면, 이름은 누구를 위한 걸까
  • 한 군데만 s 로 바꾼다 — 이번엔 어떻게 되나
  • score = score + 10; 두 줄의 순서를 바꾼다 — 결과가 달라지나
에러 메시지는 잔소리가 아니라 힌트다. 오늘 본 에러를 세 개 모아 오자.
02 · 문자열

글자는 따옴표를
입고 다닌다

let playerName = "민준"; let greeting = "안녕, " + playerName + "!"; console.log(greeting);
따옴표 안은 글자 그대로다. 따옴표 밖의 playerName 은 이름표라서 값으로 바뀐다.
같은 글자라도 안에 있느냐 밖에 있느냐로 뜻이 완전히 달라진다.
직접 해볼 실험

이 둘은
왜 다를까

A console.log( 3 + 4 ); → 7 B console.log( "3" + 4 ); → "34" C console.log( "3" + "4" ); → ? D console.log( "3" * 4 ); → ?
C와 D는 먼저 예측하고 실행한다. D가 놀랍다면, 그게 오늘 제일 중요한 발견이다.
고장 내기 2

따옴표를
하나만 지운다

해볼 것

"안녕, " 의 뒤쪽 따옴표 삭제

에러가 어디를 가리키나? 진짜 잘못된 줄과 같은 줄인가?

알게 되는 것

에러 위치는 자주 어긋난다

컴퓨터는 “여기서 이상해졌다”고 말할 뿐, 원인이 거기 있다는 뜻은 아니다.

이게 앞으로 디버깅의 전부다 — 에러가 가리킨 곳부터 위로 거슬러 올라간다.
03 · 연산

문제 · 데미지 계산기

let attack = 12; let defense = 5; let critical = 2; let damage = (attack - defense) * critical;
괄호가 없으면 어떻게 되나? 괄호를 지우고 다시 계산해 본다.
값 추적표를 한 번 더 그린다 — 이번엔 damage 한 칸을 채우기 위해 머릿속으로 세 단계를 거쳐야 한다.
잘 쓰이는 것

나머지 % 는
생각보다 자주 나온다

10 % 3 → 1 (10을 3으로 나눈 나머지) 7 % 2 → 1 홀수 8 % 2 → 0 짝수
“짝수인가?”를 코드로 묻는 방법이다. 2부 조건문에서 바로 다시 만난다.
읽기 4동작 · 마지막

이번엔 내가
설명하고 AI가 채점한다

아래는 내가 읽은 코드와, 내가 한 설명이야. 코드 (코드 붙여넣기) 내 설명 (내가 한 줄씩 한국어로 쓴 것) 내 설명에서 틀린 곳만 짚어줘. 맞는 설명을 대신 써주지는 마. 어디가 틀렸는지만 말해줘. 내가 빠뜨린 줄이 있으면 그 줄 번호만 알려줘.
AI에게 설명을 시키면 내가 이해한 게 아니다. 순서를 뒤집어야 내 것이 된다.
