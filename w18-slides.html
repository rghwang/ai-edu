01 · 변수

값에 이름 붙이기

let score = 70; score = 90; // 바꿀 수 있다 const name = "민준"; // name은 다시 바꾸지 않는다

let = 바뀔 값 · const = 바꾸지 않을 값

값의 종류

컴퓨터는 값의 종류도 본다

number

42 · 3.14

계산할 수 있는 숫자

string

"안녕하세요"

따옴표로 감싼 글자

boolean

true · false

맞다 또는 아니다

"10"은 글자, 10은 숫자다. 생김새가 같아도 종류가 다르다.
02 · 연산자

계산하고 비교하기

계산

+   −   *   /   %

7 % 2는 나머지 1. 홀수·짝수 판별에 쓴다.

비교

===   !==   >   >=

score >= 70의 결과는 true 또는 false.

const score = 7 / 10 * 100; console.log(score); // 70 console.log(score >= 70); // true
실습 1

실행 전에 결과부터 예상

let apples = 3; apples = apples + 2; const hasEnough = apples >= 5; console.log(apples); console.log(hasEnough);

무엇이 출력될까?

숫자 하나를 바꾸면?

03 · 조건문

조건에 따라 다른 길

const score = 85; if (score >= 90) { console.log("최고!"); } else if (score >= 70) { console.log("통과!"); } else { console.log("다시 도전!"); }
위에서부터 검사하고, 처음으로 참이 된 한 길만 실행한다.
실습 2

나이 판별기를 완성하자

const age = 12; if (age >= 14) { console.log("중학생"); } else { console.log("초등학생"); }

나이가 14일 때, 13일 때, 10일 때 결과를 먼저 말하고 실행한다.

04 · 반복문

같은 일을 여러 번

for (let i = 1; i <= 5; i++) { console.log(i); }
시작

let i = 1

계속 조건

i <= 5

변화

i++

반복 비교

for와 while

횟수가 보일 때

for

“다섯 번 반복”, “1부터 10까지”처럼 횟수가 분명할 때.

조건만 보일 때

while

“에너지가 남은 동안”처럼 언제 끝날지 모를 때.

let energy = 3; while (energy > 0) { console.log("한 걸음"); energy--; }
05 · 함수

자주 하는 일을 하나로 묶기

function greet(name) { return "안녕, " + name + "!"; } console.log(greet("서준")); console.log(greet("지우"));
입력 name → 일 인사말 만들기 → 출력 return으로 결과 돌려주기
함수 실습

두 수를 더하는 기계

function add(a, b) { return a + b; } const result = add(3, 4); console.log(result);

multiply(a, b) 함수를 만들어 두 수의 곱을 돌려주자.
