W1 — 고르기 + 환경 정리 + 이미지 맛보기

첫 시간의 진짜 목표는 '내가 고른 걸 만든다'는 자립의 첫 근육과, 앞으로 8주를 받쳐줄 작업 환경을 세우는 것. 이미지(Gemini)는 가볍게 맛만 본다.

준비 체크리스트

계정

교사 Claude Pro 구독 확인 — Claude Code 공용 빌드용. 아이들은 Claude 본인 계정 불가(18세 이상)이라, 항상 교사 계정으로 함께 사용.
이미지 생성 테스트 — 교사/공용 계정에서 Gemini 이미지가 실제로 만들어지는지 미리 한 번. 감독 자녀 계정엔 이미지 생성이 아직 없을 수 있음 → W1 이미지는 공용 화면으로.
중2 — Gemini 사용 확인(만 13세 이상, 부모 동의·감독). 이미지 생성은 18세 미만 제한(후속 수정만 가능, 직접 편집·업로드 이미지 생성 불가)일 수 있음.
초4 — Family Link에서 Gemini 앱 '켜기'(기본 꺼짐). 자녀 선택 → 설정 → Gemini → 켜기. 한국은 지원 지역(EEA·영국·스위스 미지원), 순차 출시라 안 켜지면 몇 시간 뒤 재시도.

기기 · 환경

공용 작업 기기 1대 + 큰 화면/프로젝터 — 이미지 생성과 Claude Code 시연용.
저장소 통일 — 아이패드·맥이 섞여 막혔던 문제 해결책: 작품은 공용 클라우드 폴더 하나(예: 공유 드라이브)로 모은다. 기기가 달라도 저장 위치는 같게.
종이 '프로젝트 노트' 인원수만큼 — 화면 밖 자립용(고르기·계획·막힘 기록).

수업 자료

학생용 슬라이드 띄울 준비 (아래 링크).
'프롬프트 3요소' 카드 인쇄(선택): 무엇 + 분위기 + 스타일.
빈 '우리 규칙' 포스터 게시 — 실제 작성은 W4, 오늘은 자리만.
수업 흐름 · 2시간

분 단위 진행

0:00 – 0:15
오프닝 · 새 출발 선언
  • 환영 + "오늘부터 우리가 만드는 건 내가 고른 것"이라고 분위기 잡기.
  • 북극성 한 문장 보여주기(슬라이드): "AI는 도구, 주인공은 나."
  • 오늘의 약속 3개 예고 — ①내가 고른다 ②막히면 시도한다 ③수업 밖에서도 한다.
0:15 – 0:35
돌아보기 · 내 작품 자랑 + 포트폴리오 만들기
  • 지난에 만든 게임·앱·음악 중 하나씩 1분 자랑.
  • '내 작품' 폴더를 공용 클라우드에 만들고 지난 작품을 모은다 → 기기 차이 문제를 여기서 정리.
  • "앞으로 만든 건 다 여기 쌓인다"고 의미 부여.
0:35 – 0:50
자립 스킬 #1 · 고르기 자립 스핀
  • 미니 레슨: "오늘부터 뭘 만들지는 선생님이 안 정해. 네가 고른다."
  • 고르기 도구(노트에): 관심사 3개 적기 → 그중 하나로 "만들고 싶은 것 한 줄".
  • 크면 줄이는 법: "전체 게임" 말고 "캐릭터 하나"처럼 작게 시작.
0:50 – 1:30
Gemini 이미지 맛보기 · 가이드형(공용 화면)
  • 교사가 공용 화면에서 Gemini 이미지 생성을 시연 (감독 계정 이미지 제한 때문에 공용으로).
  • 프롬프트 3요소: 무엇 + 분위기 + 스타일. 같이 한 문장 만들어 생성.
  • 각자 '고른 것'에 어울리는 이미지 1~2개를 교사 도움으로 만들어 포트폴리오에 저장.
  • 안전 한마디: 진짜 사람 얼굴 ✕, 내 정보 ✕ (깊은 윤리는 W4).
1:30 – 1:45
나눔
  • 각자 오늘 만든 이미지 + "내가 고른 것" 한 줄 공유.
  • 서로 한마디 — 칭찬 1개 + 궁금한 것 1개.
1:45 – 2:00
첫 집 미션 · 스스로 정하기 수업 밖이 무대
  • 틀: "이번 주에 [내가 고른 것]을 위해 집에서 [한 가지]를 해온다."
  • 화면 밖 버전(누구나): 프로젝트 노트에 아이디어·계획 그리기.
  • 화면 버전(가능하면): Gemini로 이미지 한 컷 더 — 초4는 부모와 함께.
  • "다음 주 첫 순서는 집에서 한 것 자랑"이라고 예고 → 돌아올 이유 만들기.
수준별

초4 / 중2 다르게

초4

'고르기'는 빈 선택지 메뉴(예: 동물·게임·우주 중에서)로 도와주기. 이미지·집 미션은 부모 동반이 기본. 작게, 한 컷씩.

중2

고르기는 완전히 자유. 가능하면 본인의 연구·관심 주제와 연결. 집 미션도 스스로 범위를 정하게.

기억할 것

오늘의 안전·태도 메모

Gemini는 사람이 아니고, 틀릴 수 있다를 특히 초4에게 한 번 짚어주세요. 이미지엔 진짜 사람 얼굴·개인정보를 넣지 않기. 그리고 첫 시간이라 설정이 많지만, 두 가지만은 꼭 살리세요 — 아이가 '스스로 골랐다'는 경험과 집으로 가져갈 작은 미션 하나. 이 둘이 자립의 출발점입니다.
