W1 — 이미지·영상 맛보기 + 고르기

첫 시간은 Gemini 이미지로 손을 풀고 → '내가 뭘 만들지 스스로 고른' 뒤 → 만든 그림을 영상으로 움직여 본다. 이미지·영상을 한 번에 가볍게 맛보고, 만든 건 공유 폴더에 모은다.

준비 체크리스트

계정

교사/공용 Gemini 계정 준비 — 이번 시간의 핵심 도구. 아이들은 본인 계정으로 이미지 생성이 막힐 수 있어, 항상 공용 계정·공용 화면으로 함께 사용. (Claude Pro 구독 확인은 W1에선 불필요)
이미지 생성 테스트 — 교사/공용 계정에서 Gemini 이미지가 실제로 만들어지는지 미리 한 번. 감독 자녀 계정엔 이미지 생성이 아직 없을 수 있음 → W1 이미지는 공용 화면으로.
영상 생성 테스트(Veo) — 공용 계정에서 짧은 영상이 실제로 만들어지는지 미리 한 번. 영상은 보통 유료 플랜 + 하루 횟수 제한 → W1 영상은 교사 공용 화면으로 맛보기.
중학생 — Gemini 사용 확인(만 13세 이상, 부모 동의·감독). 이미지 생성은 18세 미만 제한(후속 수정만 가능, 직접 편집·업로드 이미지 생성 불가)일 수 있음.
초등 고학년 — Family Link에서 Gemini 앱 '켜기'(기본 꺼짐). 자녀 선택 → 설정 → Gemini → 켜기. 한국은 지원 지역(EEA·영국·스위스 미지원), 순차 출시라 안 켜지면 몇 시간 뒤 재시도.

기기 · 환경

공용 작업 기기 1대 + 큰 화면/프로젝터 — Gemini 이미지 생성 시연용.
구글 드라이브 공유 폴더 미리 만들기 — 아이패드·맥이 섞여 막혔던 문제 해결책: 작품은 구글 드라이브 공유 폴더 하나로 모은다. 오늘 만든 이미지부터 여기 저장. 기기가 달라도 저장 위치는 같게.
종이 '프로젝트 노트' 인원수만큼 — 화면 밖 자립용(고르기·계획·막힘 기록).

수업 자료

학생용 슬라이드 띄울 준비 (아래 링크).
'프롬프트 3요소' 카드 인쇄(선택): 무엇 + 분위기 + 스타일.
빈 '우리 규칙' 포스터 게시 — 실제 작성은 W4, 오늘은 자리만.
수업 흐름 · 2시간

분 단위 진행

0:00 – 0:12
오프닝 · 새 출발 선언
  • 환영 + "오늘부터 우리가 만드는 건 내가 고른 것"이라고 분위기 잡기.
  • 북극성 한 문장 보여주기(슬라이드): "AI는 도구, 주인공은 나."
  • 오늘의 약속 3개 예고 — ①내가 고른다 ②막히면 시도한다 ③수업 밖에서도 한다.
0:12 – 0:42
Gemini 이미지 맛보기 · 가이드형(공용 화면)
  • 먼저 손부터 푼다 — 교사가 공용 화면에서 Gemini 이미지 생성을 시연 (감독 계정 이미지 제한 때문에 공용으로).
  • 프롬프트 3요소: 무엇 + 분위기 + 스타일. 다 같이 한 문장 만들어 한두 개 생성하며 감 잡기.
  • 안전 한마디: 진짜 사람 얼굴 ✕, 내 정보 ✕ · Gemini도 틀릴 수 있음 (깊은 윤리는 W4).
0:42 – 1:02
자립 스킬 #1 · 고르기 (이미지·영상으로 뭘 만들지) 자립 스핀
  • 미니 레슨: "방금 해봤지? 이제 네가 뭘 만들지 고른다. 선생님이 안 정해."
  • 고르기 도구(노트에): 관심사 3개 적기 → 그중 하나로 "이미지로 만들고 싶은 것 한 줄". (이게 곧 영상의 재료가 된다고 살짝 예고)
  • 크면 줄이는 법: "전체 장면" 말고 "캐릭터 하나"처럼 작게 시작.
1:02 – 1:27
내가 고른 이미지 만들기 + 저장
  • 각자 '고른 것'에 어울리는 이미지 1~2개를 교사 도움으로 생성. 진행·대처는 Gemini 가이드 참고.
  • 만든 이미지는 구글 드라이브 공유 폴더에 저장 — 기기가 달라도 같은 곳에.
  • 초등 고학년은 공용 화면·부모 도움으로. 작게, 한 컷씩.
1:27 – 1:47
Google Flow 영상 맛보기 · 내 그림을 움직이게 (공용 화면)
  • 오늘의 하이라이트 — 방금 만든 그림 몇 개를 골라 교사가 Google Flow에 올려 영상으로 움직이게(Frames to Video) 시연.
  • 영상 프롬프트 = 무엇 + 어디서 + 어떻게 움직임 + 분위기. 다 같이 한 문장 만들어 한 편 생성.
  • 영상은 Gemini 채팅 말고 Flow로 — 구독 Flow 크레딧을 쓰면 채팅(하루 몇 편)보다 여유롭다. 교사 공용 계정으로, 만든 영상은 공유 폴더에 저장.
  • 안전: 진짜처럼 보이는 영상은 만들지·퍼뜨리지 않기 (진짜/가짜는 W2, 윤리·규칙은 W4). 자세한 진행은 Gemini 가이드 참고.
1:47 – 2:00
나눔 + 첫 집 미션 수업 밖이 무대
  • 각자 오늘 만든 이미지(와 영상) + "내가 고른 것" 한 줄 공유. 서로 칭찬 1개 + 궁금한 것 1개.
  • 집 미션 틀: "이번 주에 [내가 고른 것]을 위해 집에서 [한 가지]를 해온다." (이미지 한 컷 더 / 영상 도전 / 노트에 계획 — 초등 고학년은 부모와 함께)
  • "다음 주 첫 순서는 지난 한 주에 혼자 해본 것 자랑"이라고 예고 → 돌아올 이유 만들기.
수준별

초등 고학년 / 중학생 다르게

초등 고학년

'고르기'는 빈 선택지 메뉴(예: 동물·게임·우주 중에서)로 도와주기. 이미지·집 미션은 부모 동반이 기본. 작게, 한 컷씩.

중학생

고르기는 완전히 자유. 가능하면 본인의 연구·관심 주제와 연결. 집 미션도 스스로 범위를 정하게.

기억할 것

오늘의 안전·태도 메모

Gemini는 사람이 아니고, 틀릴 수 있다를 특히 초등 고학년에게 한 번 짚어주세요. 이미지엔 진짜 사람 얼굴·개인정보를 넣지 않기. 그리고 첫 시간이라 설정이 많지만, 두 가지만은 꼭 살리세요 — 아이가 '스스로 골랐다'는 경험과 집으로 가져갈 작은 미션 하나. 이 둘이 자립의 출발점입니다.
