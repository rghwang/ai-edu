W7 — 내 관심사 도감 사이트

좋아하는 주제로 '나만의 도감 웹사이트'를 만든다. 예: 세계 축구 선수 도감, 좋아하는 동물 도감. 한 시간에 주제 고르기 → 스스로 찾기 → '이거 진짜야?' 확인 → 사이트까지 만들어 본다.

자립 스킬
스스로 찾기 + 확인
도구
Gemini (리서치·Canvas)
결과물
도감 사이트
집 미션
항목 더 조사·확인
사전 준비 · 수업 전에 끝내둘 것

준비 체크리스트

계정

Gemini Canvas 사용 확인 — 사이트는 Gemini Canvas로 만든다(프롬프트로 코드 생성·미리보기). 기본 기능은 무료. 어린 학생은 공용/교사 계정으로 함께.
중학생 — Gemini 리서치 확인. 채팅·검색은 13세 이상 감독 계정에서도 됨(이미지·일부 기능만 제한될 수 있음).
초등 고학년 — Gemini(Family Link)로 리서치 가능. 이미지·Canvas는 공용 화면으로(감독 계정 일부 기능 제한).
선택 — 더 복잡한 앱·게임을 만들 거라면 Claude Code(유료·18세 이상)가 더 강하지만, 이 커리큘럼은 Gemini만으로 충분.

시연 · 기기

도감 사이트 샘플 1개 미리 만들어두기 — 예: '축구 선수 도감' 3항목짜리. 시작할 때 "이런 걸 만든다"고 보여주면 이해가 빠름.
공용 스테이션 + 큰 화면(Gemini Canvas 빌드용), 리서치할 학생 기기.
프로젝트 노트 — 찾은 정보·확인 결과를 적는 곳. 완성 사이트는 공용 폴더/포트폴리오에 저장.

수업 자료

학생용 슬라이드 띄울 준비 (아래 링크).
수업 흐름 · 2시간

분 단위 진행

0:00 – 0:25
집에서 한 것 자랑 + 오늘 소개 수업 밖이 무대
  • 지난 주 이후 혼자 해본 것이 있으면 자랑부터 — 있으면 잘한 점 1개씩 짚기(없어도 OK).
  • 오늘 미션 공개: "네 관심사로 도감 사이트를 만든다." 샘플(축구 선수 도감 등) 보여주기.
0:25 – 0:40
자립 스킬 · 스스로 찾기 + "이거 진짜야?"
  • AI가 준 정보를 그대로 믿지 않기. 도감에 넣을 거니까 한 번 확인.
  • 확인하는 법: 다른 데서도 같은 말인지 보기 / 너무 이상하면 다시 묻기.
0:40 – 1:00
고르기 + 리서치
  • 도감 주제 정하기(축구 선수 · 동물 · 캐릭터 · 자동차…).
  • Gemini로 항목 5개와 각 정보(이름·소속·특징 등) 모아 프로젝트 노트에 정리.
  • 그중 1~2개는 진짜인지 직접 확인.
1:00 – 1:40
사이트 만들기 (Gemini Canvas, 공용 스테이션)
  • Gemini에서 Canvas를 켜고, 모은 내용을 "이런 도감 사이트 만들어줘"로 뼈대 생성 → 미리보기 보며 항목 채우기.
  • 여럿이면 로테이션: 한 명이 스테이션에서 빌드하는 동안, 다른 학생은 리서치·이미지. 그다음 교대.
  • 이미지는 공용 화면에서 함께 만들어 넣기(진짜 얼굴·개인정보 ✕).
1:40 – 1:55
나눔
  • 지금까지 만든 사이트 보여주기.
  • "확인해서 고친 정보 하나" 공유 — 검증을 칭찬.
1:55 – 2:00
집 미션 · 스스로 정하기 자립
  • "내 도감에 넣을 항목 1~2개 더 조사해서, 진짜인지 확인까지 해 노트에 적어오기."
  • 집에서 항목을 더 채워 사이트를 완성해 보라고 격려. (다음 주는 새 주제로!)
수준별

초등 고학년 / 중학생 다르게

초등 고학년

항목 3개로 작게. 빌드는 교사가 옆에서 도와주고, 이미지는 공용 화면. 리서치도 한두 단계 같이.

중학생

항목 더 많이. 사이트 구조(메뉴·카드)를 직접 프롬프트로 설계. 본인 Gemini로 리서치하고 출처도 한 번 따져보기.

기억할 것

오늘의 포인트

검증("이거 진짜야?")이 따로 떼면 시시하지만, 내 도감에 들어갈 정보라서 의미가 생깁니다 — 그게 오늘의 핵심이에요. 사이트는 오늘 뼈대 + 항목 몇 개까지 만들고, 더 꾸미고 채우는 건 집에서 이어가면 됩니다. 막혀도 괜찮아요 — 빌드하다 막히는 순간이 바로 '막힘 뚫기'를 가르칠 진짜 기회예요.
