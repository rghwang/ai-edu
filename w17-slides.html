로그인 ② · 안전

비밀번호는 화면에 남기지 않는다

  • 선생님이 준 진짜 사이트 주소로 들어간다.검색 광고나 비슷하게 생긴 주소를 누르지 않는다.
  • 공용 기기에서는 비밀번호 저장을 누르지 않는다.
  • 인증번호·비밀번호는 문서, 채팅, 화면 캡처에 넣지 않는다.
  • 끝나면 프로필 사진 → 로그아웃한다.
Google Docs

새 문서를 만들고 먼저 이름 붙이기

  • docs.google.com 또는 Google Docs 앱을 연다.
  • 빈 문서 또는 ＋를 누른다.
  • 제목을 이름_과제명_날짜로 바꾼다.예: 홍길동_17회차연습_20261004
  • 한 줄 입력하고, 문서 목록으로 나갔다 돌아와 저장됐는지 본다.
Google Docs는 보통 자동 저장된다. 그래도 문서 이름과 저장된 계정은 내가 확인해야 한다.
화면 캡처

기기마다 버튼은 달라도
결과는 사진 파일 한 장

Mac

⌘ ⇧ 4

범위 선택. 전체 화면은 ⌘ ⇧ 3.

Windows

Win ⇧ S

캡처할 영역을 드래그.

iPad · iPhone

윗/옆 + 음량↑

홈 버튼 기기는 윗/옆 + 홈.

Android

전원 + 음량↓

기기에 따라 빠른 설정의 ‘캡처’ 사용.

캡처 직후 필요한 부분만 자르고, 이름·비밀번호·알림 등 개인정보가 없는지 확인한다.
OctoStudio

작품 화면을 증거로 남기기

  • OctoStudio에서 제출할 프로젝트를 연다.
  • 보여주고 싶은 장면까지 직접 실행한다.
  • 도구 메뉴가 아니라 작품이 잘 보이는 순간에 화면 캡처한다.
  • 사진 앱 또는 캡처 폴더에서 열어 제대로 찍혔는지 본다.

한 장만 봐도 “무엇을 만들었는지” 알 수 있게!

태블릿 · 핸드폰

＋ → 이미지

사진 또는 카메라에서 캡처를 고른다. 사진 접근 허용이 필요할 수 있다.

  • 이미지를 누르고 모서리를 잡아 크기를 조절한다.
  • 사진 아래에 무엇을 보여주는지 한 줄 설명을 쓴다.
종이 스캔

손글씨도 반듯한 파일이 된다

  • 밝은 곳에서 종이를 평평하게 놓는다.
  • Google Drive·메모 앱 등의 스캔 기능을 연다.없으면 카메라로 찍고 자르기·회전·밝기 보정을 한다.
  • 네 모서리를 맞추고 그림자·손가락이 없는지 본다.
  • 여러 장이면 순서를 맞춰 한 파일로 저장한다.
  • Google Docs에는 이미지로 넣거나, 저장한 PDF를 과제에 따로 첨부한다.

동영상 편집 → MP4

잘라내고, 이어 붙이고, 내보내기

  • 사진 앱·기본 편집기·iMovie 등에서 영상을 연다.
  • 앞뒤의 기다리는 부분과 실수한 부분을 자른다.
  • 필요한 영상만 순서대로 이어 붙인다.
  • 내보내기·저장·공유를 눌러 동영상 파일을 만든다.
  • 파일 이름 끝이 .mp4인지 확인하고 처음부터 끝까지 재생한다.
편집 프로젝트와 제출할 MP4는 다르다. 다른 기기에서도 재생되는 MP4 파일이 필요하다.

과제 사이트 제출

올렸다고 끝이 아니다

  • 과제 사이트에 로그인하고 내 이름·과제명·마감일을 확인한다.
  • 첨부·파일 선택 버튼을 누르고 PDF 또는 MP4를 고른다.
  • 업로드가 끝날 때까지 화면을 닫지 않는다.
  • 화면의 파일 이름이 내가 고른 파일과 같은지 확인한다.
  • 제출 버튼을 누르고, 제출 완료 문구·시간·상태를 확인한다.
