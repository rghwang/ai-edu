셋이 어떻게 이어지나

셋은 한 줄로 이어집니다. 하나가 저장, 하나가 배포, 하나가 코딩 도구.

GitHub

내 작품(코드)을 저장하는 클라우드 창고. 계속 쌓이고, 되돌리기(버전 관리)도 됨.

Vercel

GitHub 창고에 올리면 자동으로 인터넷 주소를 만들어 웹에 올려주는 서비스.

Claude Code 웹

브라우저(claude.ai/code)에서 코드를 짜고 GitHub에 올려주는 AI 도구. 설치 불필요.

한 줄 흐름
만든다(Claude Code) → GitHub에 저장(push) → Vercel이 자동으로 웹에 올림 → 친구·가족이 링크로 본다.
미리 해둘 셋업 · 한 번만 (공용 계정)

교사 준비 4단계

전부 무료 플랜으로 충분. 교육용 이메일로 클래스 공용 계정을 만든다(아이들은 여기에 로그인만 함, 18세 미만이라 본인 계정 대신).

1
클래스 GitHub 계정 만들기

github.com에서 교육용 이메일로 계정 1개(예: 클래스 공용). 무료. 모든 작품 코드의 창고가 된다.

2
Vercel 계정 만들기 + GitHub 연결

vercel.com에서 "Continue with GitHub"로 그 GitHub 계정으로 로그인(별도 가입 없이 연결). 무료 Hobby 플랜. 이후 GitHub repo를 Import하면 push할 때마다 자동 배포.

3
Claude Code 웹 연결

교육용 개인 Claude Pro 계정(회사 계정 아님)으로 claude.ai/code 접속 → GitHub 연결 승인. 이제 브라우저에서 코드를 짜고 바로 push할 수 있다.

4
테스트 배포 1번

repo 하나 만들어 Claude Code로 "간단한 웹페이지 만들어줘" → push → Vercel에 URL이 뜨는지 확인. 되면 셋업 끝. 이후 아이별/작품별로 repo만 새로 만들면 됨.

프로젝트 규칙 — 아이별·작품별 repo 하나씩. 이름 규칙(예: jiwoo-game). Vercel이 각 repo를 각각의 URL로 배포.
아이들에게 · 30초 설명

이렇게 말해주면 충분

"우리가 만든 걸 GitHub이라는 창고에 저장하면, Vercel이 자동으로 인터넷 주소를 만들어줘. 그 링크를 친구·가족한테 보내면 진짜로 열어볼 수 있어!" — 개념은 이 정도면 충분하고, 실제 push·배포는 Claude Code가 대신 해줍니다. 아이는 '무엇을 만들지'에 집중.
아이패드 · 계정 · 안전

챙길 것

아이패드 = 전부 브라우저 — github.com · vercel.com · claude.ai/code 모두 사파리/크롬에서. 앱 설치 불필요, 공용 계정 로그인만.
공용 계정 하나로 관리 — GitHub·Vercel·Claude 모두 클래스 공용 계정(18세 이상). 아이들은 로그인해서 함께 사용(동시 사용이 많으면 Claude 사용량 한도 주의).
공개 범위 — repo·배포는 기본 공개(Public)라 링크로 누구나 봄. 진짜 이름·사진·개인정보가 든 건 올리지 않기. 필요하면 Private으로.
모두에게 필요한 건 아님 — 이미지·웹툰·애니·슬라이드 등 대부분은 구글 드라이브면 충분. GitHub·Vercel은 '진짜 배포되는 앱·게임'을 만드는 아이(주로 캡스톤)에게만.
